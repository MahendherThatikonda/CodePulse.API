# CodePulse API

A RESTful API backend built with ASP.NET Core, designed to power a full-stack 
blogging/content platform with Angular v20 on the frontend.

## Overview

CodePulse is a content management API that demonstrates clean RESTful architecture, 
dependency injection, and modern .NET backend development practices. Built to work 
seamlessly with an Angular frontend for a complete full-stack application.

## Features

- **RESTful API Design** — Clean, resource-based endpoints following REST conventions
- **ASP.NET Core** — Built on .NET's modern, cross-platform web framework
- **Dependency Injection** — Loosely coupled architecture for maintainability and testability
- **Angular v20 Frontend** — Paired with a modern Angular frontend for full-stack coverage
- **Structured Project Layout** — Organised for scalability and separation of concerns

## Tech Stack

| Layer | Technology |
|---|---|
| Backend Framework | ASP.NET Core |
| Language | C# |
| Architecture | RESTful API, Dependency Injection |
| Frontend (paired) | Angular v20 |
